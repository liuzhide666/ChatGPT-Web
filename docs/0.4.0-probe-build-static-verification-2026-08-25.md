## Byte-scan boundary

A raw all-dependency DEX string scan is not equivalent to an app implementation scan. The pinned GeckoView 153 AAR itself defines the public `GeckoSessionSettings.userAgentOverride` API and its `SessionAccessibility` implementation references `android.webkit.WebView` for Android accessibility compatibility; AndroidX Core `LinkifyCompat` also references that platform type. These dependency-owned symbols remain in the APK because GeckoView 153 is frozen and removing its accessibility implementation would alter/break the pinned engine.

The application-owned source and DEX contain no WebView construction/use, WebChromeClient, WebView PermissionRequest, SpeechRecognizer, RecognizerIntent, native dictation, JavaScript permission bridge, or Chrome UA override call. Therefore this APK has one GeckoView engine and no app-level WebView fallback or UA spoofing, but it must not be described as having zero byte-level occurrences of the words `WebView` or `userAgentOverride` across third-party dependency code.
